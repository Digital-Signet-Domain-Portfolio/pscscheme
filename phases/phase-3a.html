PSDS Phase 3a: historical record

Phase 3a opened the multi-year £1.425bn PSDS Phase 3 funding envelope [DESNZ]. It used a first-come-first-served queue model that was later replaced.

Budget and timing

Phase 3a was the first sub-phase of the PSDS Phase 3 funding programme spanning 2022/23 to 2024/25. Funded projects appear in the DESNZ phase-3 list [DESNZ].

Awards and school share

The Phase 3 funded-projects list covers all sub-phases collectively; sub-phase splits require parsing the publication date metadata. Schools, academies and FE colleges feature prominently across heat-pump, fabric and LED bundles.

£/tCO2e profile

Earlier Phase 3 awards used a less binding £/tCO2e test than the Phase 4 ceiling.

Lessons fed forward

Phase 3a established the procurement-route discipline and the GIFA + fossil-kWh evidence base that the Salix portal now requires by default.
